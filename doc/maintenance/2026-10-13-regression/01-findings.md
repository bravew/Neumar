## Consider: unresolved requirements and architecture debt

These are follow-up investigations, not deletion or implementation orders.

- **Restore semantics.** `packages/video-ir/src/transcript-edit.ts:366` rejects restore when an unrelated empty caption track is present. The reviewer reproduced the difference. Confirm whether this conservative rule is intended before narrowing it.
- **Translation budgets.** `src-api/src/shared/video/caption-translate.ts:483-490` documents a deliberate choice: translation runs on the already-selected Video Mode model with no separate spend approval or budget debit. That may be correct. Confirm the user-facing claim matches this choice, then either keep the documented behavior with a test or add the agreed approval/accounting path.
- **Fork cost.** `branch-sdk-session.ts:134` forks from a parent; `claude/stream-signals.ts:516` settles against the new session's baseline. Double-counting is conditional on SDK fork cost semantics. Reproduce with a controlled SDK fixture/live trace before labeling a confirmed billing defect.
- **Migration drift.** `shared/db/migrations/utils.ts:20` does not distinguish a missing table from a missing column. #44 repaired `video_intent_log` drift and added full-registry regression coverage. Audit other ALTER callers against supported upgrade histories. Silently skipping every absent table would hide corruption and is not the fix. File numbering and migration versions already differ; do not renumber applied migrations for cosmetic consistency.
- **Tool typing.** `shared/mcp/video-edit-server.ts:2562-2625` resolves tool references through `args: never` and broad casts. #102/#103 repaired test compilation but left this type boundary hard to use. Introduce a typed wrapper with valid-input compile checks and intentional invalid-input runtime tests. Keep test casts only where they deliberately exercise an invalid boundary.
- **App-data isolation.** `shared/services/git-workspace.ts:27-30` derives app-owned repositories/sessions from `homedir()`; `publish/destinations/local-archive.ts:30` defaults to the old brand directory. Trace callers and injected roots, then test `NEUMAR_APP_DATA_DIR`. Plan compatibility for existing archives before changing paths.
- **Unsupported routes.** `/plugins/:id/apply` with `surface: 'chat'` returns 501; `/memory/entities/extract` and `/memory/consolidate` return 501 and explicitly direct callers to supported alternatives. Trace UI/external callers before deciding whether to implement, hide, document, or retire them. Platform-native dialog 501 responses can be correct capability behavior.
- **Deferred SDK requirements.** #96 explicitly deferred ambient-task filtering; profile delegates receive `omitClaudeMd: true`. Confirm coding-profile instruction policy and track deferred behavior separately from the completed timeout work.

## Dismissed or not established

- Size, zero review records, a non-conventional title, casts, or a grep match alone do not establish a defective PR or malicious intent.
- Empty-string defaults, raw fetch, home-directory calls, prefix checks, and cleanup catches each have legitimate uses. Review invalid-state masking and trust boundaries, not blanket substitutions.
- React lint warnings identify review work, not 453 independently reproduced defects. The baseline is 254 set-state-in-effect, 137 refs, 22 static-components, 16 exhaustive-deps, 14 preserve-manual-memoization, 6 incompatible-library, 2 purity, and 2 immutability warnings.
- #102's apparent bulk is mostly a newly tracked Cargo.lock; stacked PR #103 statistics include earlier work. Use squash-commit diffs to attribute changes.
- #176 retains its meaningful failure assertions. Adding namespaces to a translation mock and an explicit undefined call argument is not assertion weakening.
- `getByText(...).toBeTruthy()` can be meaningful because `getByText` throws on absence. Route tests mocking service dependencies are not necessarily mocking their own subject.
- No full reachability proof, exploit exercise, packaged-app run, live SDK cost test, or complete supply-chain audit was performed. Suspected issues remain separate until their proposed regressions establish them.
