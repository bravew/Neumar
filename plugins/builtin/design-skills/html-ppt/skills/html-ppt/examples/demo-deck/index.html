How · Core idea

Move visual identity into :root

Concept

Every visual property, from color and type to radius and shadow, becomes a semantic token.

  • --text-1 / --text-2 / --text-3
  • --surface / --surface-2
  • --accent / --accent-2 / --accent-3
  • --radius / --shadow / --grad

Example

/* assets/themes/aurora.css */
:root {
  --bg: #06091c;
  --text-1: #e8f0ff;
  --accent: #5ef2c6;
  --accent-2: #7aa2ff;
  --accent-3: #c984ff;
  --radius: 20px;
}

——That is the whole aurora theme.

how
The key is that base.css only reads variable names, not raw values. Changing theme means changing variables.
