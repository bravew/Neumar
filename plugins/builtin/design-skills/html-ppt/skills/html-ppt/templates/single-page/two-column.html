Concept ⟷ example

Left column · concept

One theme equals one set of CSS variables. Color, type, radius, and shadow all live in :root.

  • - tokens define semantics, not raw colors
  • - base.css uses tokens for layout
  • - each theme only changes variables

Right column · example

:root {
  --bg: #fff;
  --text-1: #0c0d10;
  --accent: #3b6cff;
  --radius: 18px;
}
.card {
  background: var(--bg);
  color: var(--text-1);
  border-radius: var(--radius);
}
